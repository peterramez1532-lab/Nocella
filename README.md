# Nocella Chocolates — Creative Demo

A responsive, premium chocolate e-commerce landing page inspired by the supplied Nocella logo and the requested visual direction.

## Run
1. Unzip the folder.
2. Open `index.html` in Chrome/Edge/Safari.
3. No build step is required.

## Included
- Responsive 4K-friendly desktop layout
- Mobile navigation
- Hero section
- Chocolate / Gift Box / Truffles categories
- Best sellers cards
- Cart counter interaction
- Search interaction
- Newsletter interaction
- Story section
- Nocella logo asset from the supplied image

## Notes
The demo uses Google Fonts. If opened offline, the browser will fall back to the included system font stack.
